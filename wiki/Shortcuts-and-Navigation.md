# Shortcuts & Navigation

TabFlow provides instant keyboard-driven navigation with customizable shortcuts.

---

## Default Global Shortcuts

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| <kbd>⌥ Option</kbd> + <kbd>⇥ Tab</kbd> | Summon Switcher | Opens the window switcher and cycles to next window |
| <kbd>⌥ Option</kbd> + <kbd>⇧ Shift</kbd> + <kbd>⇥ Tab</kbd> | Cycle Backward | Cycles to previous window |
| <kbd>⌥ Option</kbd> + <kbd>`</kbd> | Same App Switch | Switches only between windows of active app |

---

## Actions Inside the Switcher

While holding down the shortcut modifier:

- **Arrow Keys** (<kbd>→</kbd>, <kbd>←</kbd>, <kbd>↑</kbd>, <kbd>↓</kbd>): Navigate through window tiles.
- **Enter / Space**: Switch focus to selected window and close switcher.
- **W**: Close selected window.
- **M**: Minimize selected window.
- **H**: Hide selected application.
- **Q**: Quit selected application.
- **F**: Toggle fullscreen on selected window.
- **/**: Start typing instant search filter.
- **Esc**: Dismiss switcher without changing window focus.

All keys and behaviors can be modified in **Preferences > Controls**.
