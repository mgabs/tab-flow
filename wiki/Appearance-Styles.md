# Appearance & Customization Styles

TabFlow provides three distinct visual layout styles, custom thumbnail sizing, themes, and fine-grained visual controls.

---

## Switcher Layout Styles

In **Settings > Appearance**, you can choose between 3 switcher styles:

1. **Thumbnails (Default)**:
   - True-to-life live window previews showing full visual contents of every open window.
   - Ideal for visual multitasking and identifying documents by preview.
2. **App Icons**:
   - Clean, compact grid displaying application icons with titles.
   - Ultra-fast visual scanning with minimal screen real estate.
3. **Titles**:
   - Streamlined list/grid prioritizing window titles and application names.
   - Best for power users with dozens of similar terminal or editor windows.

---

## Window Size & Scaling

- **Auto-Size**: TabFlow automatically calculates the optimal tile grid dimensions to maximize thumbnail readability based on the number of open windows and active screen resolution.
- **Fixed Widths**: Choose manual width presets from 50px up to 400px per window card.
- **Max Dimensions**: Set maximum on-screen rows and columns to prevent the switcher from overflowing your display.

---

## Themes & Visual Materials

- **System Adaptive**: Automatically mirrors macOS Light and Dark appearance.
- **Frosted & Liquid Glass**: Seamlessly integrates macOS visual vibrancy, blur, and border rendering.
- **Show/Hide Elements**: Toggle space badges, app icons, status indicators, and colored window indicators in **Customize more…**.
