# Getting Started with TabFlow

Welcome to TabFlow! This guide walks you through installing, setting up permissions, and running your first switcher session.

---

## ⚡ Quick Start (3 Steps)

1. **Install via Homebrew**:
   ```bash
   brew install --cask mgabs/tap/tab-flow
   ```
   *(Or download the `.zip` archive from [[Installation|Installation]])*

2. **Grant Permissions**:
   TabFlow requires **Accessibility** (to detect windows & switch focus) and **Screen Recording** (to capture live window thumbnails). Follow the step-by-step guide in [[macOS Permissions Guide|Permissions]].

3. **Summon the Switcher**:
   Hold <kbd>⌥ Option</kbd> and press <kbd>⇥ Tab</kbd> to cycle windows. Release to switch.
